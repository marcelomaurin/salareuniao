# API

Serviço central da plataforma.

Domínios iniciais: autenticação, usuários, grupos, salas, reuniões, agenda, participantes, dispositivos e permissões.

Rotas sugeridas: `/auth`, `/users`, `/rooms`, `/meetings`, `/devices` e `/events`.

A implementação deverá manter versionamento de API, começando por `/api/v1`.
