# Cliente Web

Cliente principal da plataforma no navegador.

Escopo planejado: login, lista de salas/reuniões, criação de reunião, lobby, áudio/vídeo WebRTC, seleção de dispositivos, compartilhamento de tela, chat, participantes, agenda e administração.

O cliente deve consumir apenas contratos públicos de `services/api` e `services/signaling`.
