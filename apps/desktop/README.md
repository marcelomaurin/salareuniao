# Cliente Desktop

Aplicação desktop da plataforma de videoconferência.

Deve compartilhar os mesmos conceitos e protocolos do cliente Web, adicionando recursos nativos: seleção avançada de câmera/microfone, notificações do sistema, compartilhamento de janela/tela, inicialização automática opcional e integração com dispositivos da sala.

A tecnologia da implementação poderá ser definida separadamente sem alterar os contratos de backend.
